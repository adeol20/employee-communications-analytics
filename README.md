# employee-communications-analytics
Employee Communications Analytics – Data Analyst Position Exercise

## Video Presentation
**YouTube Link:** https://youtu.be/NORRQlXClgA 

## Key Findings

**1. Announcements generate higher reach**
- Announcements averaged approximately 64.7% audience reach.
- Standard posts averaged approximately 27.0% audience reach.

**2. Standard posts encourage stronger engagement**
- Standard posts generated approximately 8.1 interactions per 100 viewers.
- Announcements generated approximately 3.2 interactions per 100 viewers.

**3. High reach does not necessarily translate into action**
- Link performance varied significantly across posts.
- The benefits enrolment announcement generated relatively few clicks despite reaching a large audience.

## Recommendation
Adopt a purpose-based communications strategy:
- Use announcements for important, time-sensitive communications.
- Use standard posts to encourage employee interaction and participation.
- Review calls to action and link placement to improve employee engagement.
